# inventory-system

موقع تجريبي لإدارة طلبات الخدمات بين العميل والأدمن، ويدعم:

- إنشاء حساب وتسجيل دخول للعملاء.
- إدخال **الخدمة كنص حر** (بدل اختيارها من قائمة ثابتة).
- إدخال السعر الذي يختاره العميل والكمية والتفاصيل.
- لوحة أدمن لعرض جميع الطلبات وتحديث الحالة (`قيد المراجعة` / `قيد التطوير` / `مكتمل`).
- إشعارات داخلية للعميل عند إنشاء الطلب أو تحديث حالته.
- سجل إيميلات تجريبي داخل لوحة الأدمن (بديل محلي لإرسال البريد الحقيقي).

## التشغيل المحلي

```bash
python3 -m http.server 4173
```

ثم افتح:

```text
http://localhost:4173
```

## حساب الأدمن الافتراضي

- البريد: `admin@site.com`
- كلمة المرور: `admin123`

> ملاحظة: هذا الإصدار Frontend-only ويستخدم `localStorage` للتخزين، لذلك هو مناسب كنموذج أولي قبل ربط Backend وإرسال Email حقيقي.
